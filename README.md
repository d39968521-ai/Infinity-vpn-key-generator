# Straus Top — Universal (Android & Smart TV)

Кроссплатформенное приложение для управления подписками **Straus Top** с поддержкой **Android-смартфонов** и **Android TV / Smart TV** в едином универсальном APK.

---

## 📦 Готовый APK в файлах проекта

Готовый установочный файл сохранён прямо в репозитории проекта:
- 📄 **[`StrausTop-Universal-TV-Mobile.apk`](./StrausTop-Universal-TV-Mobile.apk)** (в корне проекта)
- 📁 **[`releases/StrausTop-Universal-TV-Mobile.apk`](./releases/StrausTop-Universal-TV-Mobile.apk)** (в папке `releases/`)

---

## ✨ Возможности

- **Универсальность (2-в-1)**: автоматически определяет устройство при запуске (`Smart TV / Android TV` или `Смартфон / Планшет`) и включает соответствующий интерфейс.
- **Smart TV 10-Foot UI и поддержка пульта (D-Pad)**:
  - Крупные карточки, высокая контрастность и масштабируемая подсветка активного элемента при навигации стрелками пульта.
  - Полноэкранный QR-код высокой чёткости для сканирования с экрана телевизора камерой телефона.
  - Поддержка иконки и баннера в лончере Android TV (`LEANBACK_LAUNCHER`).
- **Мобильный интерфейс**:
  - Пакетная генерация подписок (от 1 до 10 за раз).
  - Быстрый импорт и запуск в **Happ**, **Hiddify**, **v2rayNG**, **Clash**, **SagerNet**.
  - Скачивание конфигураций (`Clash`, `v2ray`, `Sing-box`, `Base64`).
  - Напоминания об истечении подписки и виджет для рабочего стола.
- **Цветовые палитры**: Голубая (*Sky Blue* по умолчанию), Глубокий океан, Кибер Неон, Изумрудная бирюза, Классический фиолетовый и Material You.
